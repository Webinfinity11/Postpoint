# rsline-shop

RS Line's Georgian retail equipment catalog, built with Next.js, React, and TypeScript.

## Local development

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

## Production

```sh
npm run build
npm start
```

Catalog and site content live in `src/data`. Images and fonts live in `public`.

Product prices and checkout are for demonstration. Cart and favorites are stored locally in the browser.
